Project  Requirements  
1.  Project  Title  ○  Each  team  must  identify  a  unique  project  title  within  the  section .  ○  The  project  should  address  a  meaningful  real-world  problem  and  should  not  be  a  simple  
CRUD
 
application.
 2.  Team  Formation  ○  Projects  should  be  completed  as  2  member  teams  as  approved  by  the  course  instructor.  ○  Each  team  member  must  have  clearly  defined  responsibilities  and  contribute  to  both  
database
 
and
 
application
 
development.
 3.  Database  Requirement  ○  The  project  must  demonstrate  practical  database  design  and  implementation .  ○  Students  has  to  use:  
Option  1:  SQL  +  NoSQL  
●  SQL  Database  (Mandatory):  MySQL  or  PostgreSQL  ●  NoSQL  Database:  MongoDB,  Neo4j,  etc.  
Option  2:  SQL  +  Vector  Database  
●  SQL  Database  (Mandatory):  MySQL  or  PostgreSQL  ●  Vector  Database:  PostgreSQL  with  pgvector,  Qdrant,  Pinecone,  Chroma,  etc.  ○  A  project  may  use  two  (Minimum)  or  more  database  paradigms ,  depending  on  its  
requirements.
 4.  Database  Design  ○  For  SQL-based  components,  students  must  prepare  an  ER  diagram  and  convert  it  into  a  
relational
 
schema
.
