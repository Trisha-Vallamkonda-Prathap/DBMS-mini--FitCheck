## 3. Referential Integrity Strategy (`ON DELETE / ON UPDATE`)

1. **`ON DELETE CASCADE` (Parent-Dependent Lifecycle):**
   - `BODY_PROFILE.user_id -> USER.user_id`: If an account is removed, its private body measurements are deleted automatically to protect privacy and prevent orphaned data.
   - `GARMENT_MEASUREMENT.garment_size_id -> GARMENT_SIZE.garment_size_id`: Garment measurements represent the physical dimensions of that exact manufactured size row.

2. **`ON DELETE RESTRICT` (Audit Durability & Integrity):**
   - `PURCHASE.user_id` & `PURCHASE.garment_size_id`: A user or catalog item cannot be silently deleted if historical purchase transactions reference it.
   - `FIT_REVIEW.user_id` & `FIT_REVIEW.garment_size_id`: Reviews cannot be orphaned by deleting garments.
   - `GARMENT.brand_id` & `GARMENT_SIZE.garment_id`: Prevents cascading loss of catalog hierarchy.

3. **`ON UPDATE CASCADE`:**
   - Applied across all foreign keys to maintain referential synchrony if parent surrogate identifiers are reorganized.

## 4. DDL Operations Demonstration (`ALTER` & `DROP`)

The script [`database/fitcheck_ddl.sql`](file:///C:/Users/Trisha%20V%20P/DBMS-mini--FitCheck/database/fitcheck_ddl.sql) includes executable DDL demonstrations verifying that schema manipulation works:

```sql
-- 1. Create demonstration table
CREATE TABLE ddl_demo_table (
    demo_id INT NOT NULL AUTO_INCREMENT,
    demo_code VARCHAR(20) NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
    CONSTRAINT pk_demo PRIMARY KEY (demo_id)
) ENGINE = InnoDB;

-- 2. ALTER TABLE: Add column
ALTER TABLE ddl_demo_table
    ADD COLUMN notes VARCHAR(255) NULL AFTER status;

-- 3. ALTER TABLE: Add CHECK constraint
ALTER TABLE ddl_demo_table
    ADD CONSTRAINT chk_demo_status CHECK (status IN ('ACTIVE', 'INACTIVE', 'ARCHIVED'));

-- 4. ALTER TABLE: Add index
ALTER TABLE ddl_demo_table
    ADD INDEX idx_demo_code (demo_code);

-- 5. ALTER TABLE: Drop column
ALTER TABLE ddl_demo_table
    DROP COLUMN notes;

-- 6. DROP TABLE: Clean up demonstration table
DROP TABLE ddl_demo_table;
```
